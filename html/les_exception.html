Les Exceptions en Python

Les exceptions permettent de gérer les erreurs sans interrompre brutalement l’exécution d’un programme.

Pourquoi utiliser une exception ?

Quand un programme rencontre une situation inattendue, il peut lever une exception. Cela permet d’afficher un message clair et de continuer ou d’arrêter proprement le script.

Exemple simple

try:
    nombre = int("abc")
except ValueError:
    print("Erreur : valeur invalide.")

Bloc try / except

Le code risqué est placé dans le bloc try. Les erreurs sont traitées par un ou plusieurs blocs except.

Instruction raise

On peut aussi déclencher soi-même une exception avec raise pour signaler une condition spéciale.

age = -2
if age < 0:
    raise ValueError("L'âge ne peut pas être négatif.")

Bloc finally

Le bloc finally s’exécute toujours, que l’exception soit levée ou non. Il est utile pour fermer des fichiers ou libérer des ressources.
